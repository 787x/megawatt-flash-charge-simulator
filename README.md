# 兆瓦闪充站运营模拟器

一个面向技术演示、站点方案比较和排队研究的单页 Web 应用。它模拟电网、储能、双枪充电桩、车辆队列、SOC—功率曲线与运营指标，并特别处理 A 通用枪和 B 闪充专用枪不同的车辆兼容角色。

> 本项目为非官方仿真工具。部分预设参数根据公开资料整理或拟合，仅用于技术演示，不代表厂商实际控制策略或设备性能承诺。

## 页面与功能

- 一屏式运营驾驶舱：左侧参数、中央站场、右侧实时指标、底部数据区。
- 离散时间仿真：暂停、继续、单步、1×–300×、固定随机种子重置。
- 电网与储能协同：基础负荷、电网容量、储能削峰、SOC 边界和充放电效率。
- 双枪角色感知调度：每桩固定一个 A 通用枪和一个 B 闪充专用枪。
- 五种桩内功率策略：专枪优先、公平分配、按请求比例、通用枪优先、自定义权重。
- 全局权威等待队列、兼容性诊断、分类等待时间和枪口利用率。
- 手动添加车辆、自动泊松到达、闪充/普通车辆比例与多种场景预设。
- 车辆详情、状态时间线、SOC—功率曲线编辑、事件日志与运营分析。
- 场景自动保存、命名保存、JSON 导入/导出、车辆 CSV 导出。
- 深浅主题、响应式移动布局、减少动态效果支持。

## 车辆兼容模型

车辆使用明确的 `chargingClass`：

- `flash_capable`：可使用 A 通用枪或 B 闪充专用枪。
- `standard_dc`：只能使用 A 通用枪。

所有 UI、调度和状态机均调用 `isVehicleEligibleForConnector`，不使用品牌名或“高电压”等模糊字段判断兼容性。每个等待车辆从唯一的 `queue: VehicleId[]` 派生可服务枪口；不存在 A/B 两个可重复车辆的真实队列。

## A/B 枪分配与去重

默认 `role_aware_fcfs` 调度是一次原子操作：

1. 获取全部空闲枪和等待车辆。
2. 先为 B 选择队列中最早的闪充兼容车辆并临时保留。
3. 再为 A 从剩余车辆中选择最早的兼容车辆。
4. 使用 `Set<VehicleId>` 确认一车最多分配一次，再一次性提交。
5. 提交前再次调用统一兼容函数；失败则取消，不污染队列和枪口状态。

已进入充电会话的车辆不会因其他枪释放而被抢占或迁移。

## 功率层级与硬约束

功率依次经过：车辆曲线与电压电流限制 → 枪口铭牌/策略限制 → 每桩共享限制 → 站级母线 → 电网与储能可用功率。

- 默认每枪硬上限：`1500kW`。
- 默认每桩 A+B 合计硬上限：`2100kW`。
- 多桩时，每桩先独立执行内部策略，再在桩之间使用站级剩余功率；不会把全站会话简单统一缩放后破坏桩内优先级。
- 每步运行 `assertSimulationInvariants`，检查兼容、重复分配、双向引用、功率、SOC 与队列一致性。

双枪同时请求 1500kW、整桩可用 2100kW 时：

| 策略 | A 通用枪 | B 专用枪 |
| --- | ---: | ---: |
| 闪充专枪优先 | 600kW | 1500kW |
| 公平分配 | 1050kW | 1050kW |
| 按请求比例 | 1050kW | 1050kW |
| 通用枪优先 | 1500kW | 600kW |

如果其中一枪只请求 300kW，公平算法会把剩余功率重新分给另一枪，不会固定二等分。

## SOC、储能与符号约定

车辆每步能量：

```text
deltaEnergyKWh = actualPowerKw × efficiency × deltaTimeSec / 3600
newSoc = oldSoc + deltaEnergyKWh / usableBatteryCapacityKWh × 100
```

SOC 不得下降，也不能超过目标 SOC。储能放电功率为正、充电功率为负；电网向站内供电为正。储能接近上下限时会在当前步预先限制功率。

## 参数来源分类

- 官方公开参数 / `official_public`
- 公开站点案例 / `public_case`
- 公开测试拟合 / `public_test_fit`
- 模型默认假设 / `model_assumption`
- 用户自定义 / `user_defined`

单枪 1500kW、双枪可同时工作等是公开能力描述；整桩 2100kW 作为可修改的公开案例参数。`dedicated_first` 等具体调度与功率分配算法属于模型假设，不代表厂商站控算法。A 枪 480kW 仅是可选案例策略上限，不修改 1500kW 铭牌硬上限。

## 场景 JSON

导出文件包含 `schemaVersion: 2`、场景名、电网、储能、设备、车辆比例、队列策略、功率策略和随机种子等配置。导入会校验版本、关键数值与比例范围；非法文件以中文提示并安全回退。

## CSV 导出

“导出 CSV”生成车辆明细，包含编号、类别、状态、SOC、当前功率、等待时间、充入电量和分配枪口。后续可以按同一工具函数扩展时间序列、日志和汇总分表。

## 已覆盖测试

- 曲线分段线性插值。
- 普通车不能使用 B，闪充车可使用 A/B。
- F1/S1 与 F1/F2 同时到达的角色感知分流。
- B 空闲但只有普通车等待、禁止自动迁移、防重复分配。
- 单枪 1500kW、整桩 2100kW、站级不足与多桩约束。
- 专枪优先、公平、按比例、通用枪优先和余量再分配。
- 普通车等待预测只考虑 A 枪。
- SOC 单调性、目标上限、不变量和 A/B 分类服务统计。
- 构建后页面标题、A/B 角色标签和 2100kW 文案冒烟测试。

## 已知限制与后续建议

- 当前 UI 展示一个双枪桩；引擎数据结构和功率层级已为多桩预留。
- 等待时间是兼容感知的启发式预测，尚未实现完整的前向蒙特卡洛回放。
- 储能、电价、温度和故障模型采用确定性的简化控制逻辑。
- 充电曲线编辑器已支持数值编辑与控制点增删，尚未实现直接拖拽和独立 CSV 曲线导入。
- 最值得扩展的是多桩站级功率拍卖、场景 A/B 对比和更精细的 P90/弃队敏感性分析。
